# Today — Minimal Daily Task Planner

A lightweight, distraction-free daily planner designed for one purpose:

> Open the app → instantly know what to do next.

---

## ✨ Philosophy

Most productivity apps fail because they make you plan too much.

Today removes that friction by focusing only on:
- The current day
- The next actionable task
- Zero setup

No clutter. No overwhelm. Just execution.

---

## 🚀 Features

### 🕒 Live Timeline
- Full 24-hour vertical timeline
- Real-time current time indicator
- Auto-scroll to current time

### ✅ Smart Task Management
- Add tasks in seconds
- Optional time-based or flexible tasks
- Swipe to complete

### 🎯 Next Task Highlight
- Always shows what you should do next
- Automatically determined based on time

### 📜 Past Tasks Strip
- Completed or expired tasks move to a horizontal section
- Keeps timeline clean and focused

### 🎨 Minimal, Accessible UI
- Large readable typography
- Generous touch targets
- Clean, flat design with subtle depth

### ⚡ Offline & Instant
- No login
- No backend
- No delays

---

## 🧠 Design Principles

- **Zero Learning Curve** → usable instantly
- **Single Screen UX** → no navigation complexity
- **Low Cognitive Load** → app decides priority
- **Fast Interaction** → everything within 1–2 taps

---

## 🏗 Tech Stack

- Flutter (iOS-first, Android-ready)
- Riverpod (state management)
- Hive (local storage)
- ThemeExtension (dynamic theming)

---

## 🎯 Why This App Exists

This app is built for people who:
- Don’t want complex planners
- Don’t want to “organize their life”
- Just want to **do the next thing**
